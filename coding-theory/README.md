# 编码理论简介

山东大学新生研讨课，讲授：胡思煌。

课件面向大一新生，52 页主课、7 页备查，教学安排为 120 分钟（含课间休息）。内容包含编码历史、汉明码、二维码、纠删码、5G、AI 与量子纠错。

## 浏览课件

在线课件：https://husihuang.github.io/coding-theory/ 。网页入口为本目录下的 `index.html`。下载后也可用 Edge 或 Chrome 离线打开；图片、音频和交互演示已嵌入网页，参考资料链接需要联网。

- 左右方向键翻页；行列校验与汉明译码页可逐步演示。
- `F`：全屏；`O`：目录；`N`：教师备注。
- `Home`：首页；`End`：主课最后一页。
- 极化码页可切换递归分化、4/8 信道逐层合成、编码与译码等视图。

## 编辑与重建

源码位于 `source/`。使用 Python 3，在本目录（`coding-theory/`）运行：

```sh
python build.py
```

构建使用 Python 标准库，更新 `index.html`，并生成备课讲义、教学安排和使用说明。

## 发布到 GitHub Pages

课件作为个人主页仓库的子目录发布，沿用现有 Jekyll 与 GitHub Pages 设置。提交更新后的 `coding-theory/` 目录到 `master` 分支，等待 Pages 构建完成即可。教学页面入口位于 `/teaching.html`。

## 资料来源

论文、标准、官方文档与历史照片的来源见课件内教师备注及 `source/assets/历史图片来源.txt`。阿勒坎肖像来自比尔肯特大学，华为标识和 2018 年颁奖照来自华为官网。第三方照片、标识与其他素材的权利属于各自权利人。
